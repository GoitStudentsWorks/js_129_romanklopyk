#  Солодка майстерня

«Солодка майстерня» — це сучасний і затишний веб-сайт кондитерської, створений для любителів вишуканих десертів. Проєкт розроблений командою розробників як навчальний груповий проєкт.

##  Особливості проєкту

* **Адаптивний дизайн:** Коректно відображається на мобільних телефонах, планшетах та десктопних екранах.
* **Інтерактивні елементи:** Зручна навігація, галерея бестселерів та секція частих питань (FAQ) з акордеонами.
* **Каталог десертів:** Зручний вибір ласощів за категоріями.
* **Секція «Про нас» та відгуки:** Знайомство з майстрами та реальні враження клієнтів.

##  Технології

Під час розробки використовувалися такі технології та інструменти:
* **HTML5** (семантична розмітка)
* **CSS3 / SCSS** (мобільний дизайн, Flexbox, Grid)
* **JavaScript** (інтерактивність, різні бібліотеки)
* **Vite** (збірник проєктів)
* **Git & GitHub** (командна розробка та контроль версій)

##  Структура секцій
* **Header / Hero:** Головний екран з вітальним банером.
* **Bestsellers / Dessert:** Список популярних та повний каталоги десертів.
* **About / Feedback:** Інформація про майстерню та відгуки покупців.
* **FAQ:** Розділ із відповідями на найпоширеніші запитання.
* **Footer & Modal:** Контакти, посилання на соцмережі та інтерактивні модальні вікна.

##  Команда проєкту
Проєкт розроблений спільною командою студентів у межах курсу з веб-розробки. Кожен учасник відповідав за окремі секції та загальну інтеграцію функціоналу.
